# Python Syntax, Semantics & Core Data Structures

Набор практических CLI-скриптов на чистом **Python 3** без использования сторонних библиотек. Проект охватывает базовые структуры данных, работу с файлами и кодировками, парсинг табличных данных без модуля `csv`, обработку аргументов командной строки и строковые алгоритмы.

##  Стек и принципы разработки
* **Язык:** Python 3 (исключительно стандартная библиотека, минимальный импорт `sys`)
* **Архитектура:** Изоляция логики внутри функций, отсутствие кода в глобальной области видимости, точка входа `if __name__ == '__main__':`

---

##  Структура проекта и описание задач

Весь исходный код расположен в директории `src/` и разделён на 10 модулей (`ex00`–`ex09`):

### `ex00/` — Встроенные типы данных (`data_types.py`)
* **Задача:** Декларация 8 базовых типов данных Python (`int`, `str`, `float`, `bool`, `list`, `dict`, `tuple`, `set`) и динамический вывод их типов без жесткого хардкода строк.

### `ex01/` — Конвертация CSV в TSV (`read_and_write.py`)
* **Задача:** Чтение файла `ds.csv` и замена разделителей-запятых на табуляцию (`\t`) с сохранением результата в `ds.tsv`.
* **Особенность:** Реализован ручной парсинг строк с учетом кавычек, чтобы не повредить текстовые поля, содержащие запятые внутри значений.

### `ex02/` — Поиск по ключу (`stock_prices.py`)
* **Задача:** Приём названия компании через аргумент командной строки (`sys.argv`) и вывод стоимости её акций на основе словарей компаний и тикеров (без учёта регистра).

### `ex03/` — Обратный поиск по значению (`ticker_symbols.py`)
* **Задача:** Поиск названия компании и цены акций по переданному биржевому тикеру с валидацией количества аргументов.

### `ex04/` — Группировка в словарь (`to_dictionary.py`)
* **Задача:** Преобразование списка кортежей `(страна, число)` в словарь, где ключом выступает число, а значением — список соответствующих стран.

### `ex05/` — Универсальный парсер запросов (`all_stocks.py`)
* **Задача:** Обработка строки с перечислением компаний и тикеров через запятую. Скрипт очищает пробелы, определяет тип каждого элемента (компания, тикер или неизвестное значение) и игнорирует некорректный ввод (пустые элементы между запятыми).

### `ex06/` — Многоуровневая сортировка словаря (`dict_sorter.py`)
* **Задача:** Сортировка словаря стран по убыванию числового показателя, а при равенстве значений — в лексикографическом (алфавитном) порядке.

### `ex07/` — Операции над множествами (`marketing.py`)
* **Задача:** Сегментация клиентской базы с помощью теории множеств (`set`) для трёх маркетинговых сценариев:
  * `call_center` — клиенты, не открывшие рассылку;
  * `potential_clients` — участники мероприятия, не являющиеся клиентами;
  * `loyalty_program` — клиенты, пропустившие мероприятие.

### `ex08/` — Обработка строк и генерация писем (`names_extractor.py`, `letter_starter.py`)
* **Задача:** 
  * `names_extractor.py` парсит список корпоративных адресов формата `name.surname@corp.com` и формирует TSV-таблицу `employees.tsv` с нормализацией регистра имён.
  * `letter_starter.py` находит сотрудника по email в таблице и формирует персонализированное приветственное письмо с использованием `f-strings`.

### `ex09/` — Шифр Цезаря (`caesar.py`)
* **Задача:** Кодирование и декодирование латинских строк (`encode` / `decode`) с произвольным сдвигом по алфавиту при сохранении спецсимволов и цифр. Включает валидацию входных данных и выброс исключения при обнаружении кириллицы.

##  Примеры запуска

Все скрипты запускаются из соответствующих директорий в `src/`:

* Поиск цены акций и тикеров: `python3 src/ex05/all_stocks.py 'TSLA , aPPle, Facebook'`
* Сегментация аудитории через множества: `python3 src/ex07/marketing.py potential_clients`
* Шифрование строки шифром Цезаря со сдвигом 12: `python3 src/ex09/caesar.py encode 'ssh -i private.key user@domain.ru' 12`
